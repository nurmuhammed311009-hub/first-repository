# Менің алғашқы веб-жобам

## Жоба туралы қысқаша мәлімет:
Бұл — GitHub платформасын оқып-үйренуге арналған менің ең алғашқы практикалық жобам. Жоба аясында мен репозиторий ашуды, файлдарды өзгертуді және өзгерістер тарихын (commit) сақтауды үйреніп жатырмын.
